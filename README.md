🛒 E-Commerce Website

This is a basic **E-Commerce Website** developed using HTML, CSS, and JavaScript. It showcases a range of product categories like Phones, Earphones, Laptops, Home Decor, Fashion, and Study items, and allows users to browse and add items to a shopping cart.

✨ Features:

* Interactive layout with categorized product sections
* Product listings with images, prices, and "Add to Cart" buttons
* Real-time cart count and cart item list with **remove** functionality
* Responsive design suitable for desktops, tablets, and mobile devices
* Dropdown navigation and hover effects for smooth user experience
* Contact section with email and address details

💡 Technologies Used:

* **HTML**: Structure of the web page and product sections
* **CSS**: Styling for layout, responsiveness, hover effects, dropdowns
* **JavaScript**: Cart functionality including item tracking, add/remove logic, and dynamic count update

🧾 How to Use:

1. Browse through different product categories using the navigation bar or scroll.
2. Click **"Add to Cart"** on any product to include it in your shopping cart.
3. View the cart count live on the navigation bar.
4. Check your selected items under the **"Your Cart"** section.
5. Click **"Remove"** beside any item to delete it from the cart.
